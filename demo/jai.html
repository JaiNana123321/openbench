3. Act 2: A Team can't spend more than it has ~2:00

TC-DRF-07 drf-shortfall · Requirements Draft.Quote.Line, Ledger.Account · tab 2, bob

  • Requirement: a Request is refused while its Required lines cost more than the Team's Available Balance. Optional lines don't count toward that check.
  1. New Request. Add Confocal microscope, Dec 2 09:00–17:00. Quote 480.00 (8 h × 40.00 × 1.5).
  2. Add Confocal microscope, Dec 3 09:00–12:00. Quote 180.00. Totals: Required 660.00, Available Balance 600.00, "Short by 60.00 credits".
  3. Submit. Refused: "Refused: short by 60.00 credits", with "This needs 660.00 credits; the Available Balance is 600.00." The Request stays a Draft. Expected in the test case: refused with the shortfall, 60.00. Observed: exactly that, and nothing was charged.
  4. Untick Required on line 2 (it becomes Optional) → Submit. Request #2 Allocated. Line 1 Allocated on Microscope 1; line 2 Dropped, reason "Insufficient balance: The Optional line's Quote of 180.00 credits no longer fits the Available Balance."
  5. Open Statement. One Charge of 480.00; Balance 120.00.

If something goes wrong

  • A number differs: check that the world was reset and the dates are Dec 2 and Dec 3. Then say what was expected and move on; Brian's automated run covers the same case.
  • Signed out in a tab: sign in again. Each tab's address is its own session.
  • Running late: drop Act 5, then shorten Act 1 to the room line only.
  • Don't build while the app is up: no mvn command in any terminal until Act 5 is over. A build rewrites the files the running app uses and can crash it mid-demo; we saw this in rehearsal. Stop the app (Ctrl-C) when you hand to Brian.

If the grader asks

"Is the data real?"
Yes. Every screen calls the REST API, and the data lives in PostgreSQL. The world was reset to the seed a few minutes ago.
"How do you test things that take days, like the Objection Window?"
The server reads time from one injectable clock. The automated tests move it by hand. Brian shows that.
"What if two Managers book the last room at the same instant?"
The database decides: an exclusion constraint and a per-type lock. TC-LIF-13 runs that race automatically.
