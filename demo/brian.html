If the grader asks

"Who wrote the expected results, and when?"
From the SRS, in the test case document (first draft 5 Nov), reviewed by the team. The code was then made to meet them. Where a case contradicted the SRS, we fixed the case and recorded it.
"Why integration tests instead of unit tests?"
Both exist. But allocation correctness lives in PostgreSQL (exclusion constraints and locks, per our ADR-0006), so a mock would test nothing that matters. Testcontainers gives the real database in every run.
"How long does the whole suite take?"
About 100 seconds for mvn verify: 730 tests, coverage, and the report.
"Is everything automated?"
Every case has an automated test. Two run in parts. Manual runs are still possible for any case; TESTING.md has the procedure and a run record template.
