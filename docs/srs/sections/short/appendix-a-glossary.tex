\section{Glossary}\label{app:glossary}

The vocabulary prefers the everyday word a Manager would use. Credit is the unit and never a transaction direction; there are no money words, because credits are showback, not billing. The glossary is generated at build time from the project's vocabulary file, which also lists the words each term deliberately replaces.
