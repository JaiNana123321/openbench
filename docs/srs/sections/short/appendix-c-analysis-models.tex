\section{Analysis Models}\label{app:models}

\figref{fig:states} shows the states of a Request and every transition; Section~\ref{feat:lifecycle} gives the guards. Three properties carry the design: a Hold exists only while the Request is Pending, so none outlives the Objection Window; Charges and Earnings post only on entry to Allocated; and Waiting is the one state from which a Request recovers after a refusal, a lapse, or a Bump. A typical three-class Request runs Draft, Submitted, Pending (room and GPUs on Hold, people awaiting approval), Allocated.
