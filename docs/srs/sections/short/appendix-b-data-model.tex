\section{Data Dictionary and Data Model}\label{app:data}

\figref{fig:datamodel} shows the entities the requirements name. The Inventory is the Resource Type and Resource entities with the Holds and allocations on them; the Ledger is the Account and Transaction entities; neither holds the other's information. The full specification carries the complete data dictionary with every attribute's type; the elements below are the ones the requirements depend on most.
