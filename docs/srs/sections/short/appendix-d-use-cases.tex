\section{Use Cases}\label{app:usecases}

\figref{fig:usecases} shows the twelve use cases and the actors that start them; the Clock stands for the scheduled jobs that fire when an Objection Window lapses or a Hold expires. Table~\ref{tab:usecases} gives each one's primary actor, trigger, and outcome. The full specification writes each use case out in the fields of the template: description, preconditions, postconditions, normal, alternative, and exception flows, priority, and frequency.
