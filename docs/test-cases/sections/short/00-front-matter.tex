\noindent\textbf{How to read this document.} Section~\ref{sec:intro} names the product and the build under test, the scope, and the conventions of the test case template; Section~\ref{sec:env} gives the environment, the test accounts, the test world every case starts from, the relative dates, and the reference Quotes; Section~\ref{sec:approach} gives the approach, the pass and fail criteria, and the special considerations, including how cases for features not yet built are treated; Section~\ref{sec:cases} holds the test cases, one subsection per feature of the SRS in the SRS's order, each ending with the numbers of the cases kept in the full edition only; Appendix~\ref{app:trace} maps every requirement to its test cases, and Appendix~\ref{app:glossary} defines the terms. This short edition holds the High priority test cases and the Low priority cases of the Stretch requirements, which together cover every requirement. A longer edition that adds the Medium priority cases, for secondary rules and refusals, is kept in the project repository; identifiers are the same in both.
